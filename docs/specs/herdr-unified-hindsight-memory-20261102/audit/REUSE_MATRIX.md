## Critical collisions/risks
1. Hindsight `herdr-memory` repository inaccessible via GitHub connector: STOP before changing its client until authoritative source resolved; if inaccessible, add a thin compatibility adapter from existing Herdr repo with explicit justification, not another engine.
2. Pi has OpenViking objects in several paths, including service/deployment code. Do not delete or migrate automatically.
3. Rakazo assistant memory has distinct ownership and privacy scope.
4. A bounded Rakazo pre-client queue can drop work before the durable outbox; tests must cover this.
5. `herdr-fleet` is currently missing safe session-aware rollout/rollback: cannot assume fleet-wide automatic update is safe.
6. Old October 28 deployment reports are historical evidence only.
7. Graph infrastructure may be empty in production; don't fabricate memory relations or pretend links exist.
