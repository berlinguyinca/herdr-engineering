# 07 — End-to-end workflows

W1 Morning daily briefing: scheduled time in user's timezone → check connectors with least privilege → read calendar/email/tasks where authorized → summarize with sources → notify once → task and delivery receipts. Missing connector gracefully reported without fabrication.
W2 Infrastructure triage: host unhealthy event → scoped assistant inspects canonical telemetry → bounded diagnostics/delegate Pi mission → staged proposal → approval for production change → verify health and artifact/report → no duplicate restart on replay.
W3 Research-to-spec: user asks to investigate runtime → browser/source retrieval with injection defense → compare evidence → create report/spec via existing artifact system → optionally delegate coding agent with scoped repo/worktree → link status and artifacts.
W4 Household planning: inspect authorized tasks/events → prepare plan/shopping list → draft updates → ask before modifying shared records or sending messages.
W5 Voice/mobile: speech permission → transcription → same assistant thread and authorization rules → spoken summary → transcript and privacy controls.
W6 Memory correction: show source → user corrects fact → invalidate derived memories → future retrieval uses revision → deletion verified across cache/export pipeline.
W7 Failover: start task on host A → checkpoint → host disappears → scheduler places on permitted host B → resume with dedupe of external actions → visibly reconcile ambiguous side effects.
W8 Revocation: user revokes email grant while routine queued → execution denied and notification gives remediation.
W9 Multiple users: user A's assistant cannot read B’s private objects even on shared cluster.
