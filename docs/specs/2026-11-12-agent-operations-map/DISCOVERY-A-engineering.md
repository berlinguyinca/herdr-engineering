## 5. Gaps vs the spec envelope, and integration points

Missing: `provenance(observed|derived|inferred|unknown)` (closest: `evidence_refs`, `claimed_*`); `host_id` (is in payload of session events, not envelope), `session_id`, `model_id`, `parent_session_id`, `handoff_id` as envelope fields; `status`; `sanitized_label`/`sanitized_metadata` contract; first-class event types for model switched, context metric/compaction (partly inspector `usage`/`model`), message sent/delivered/acknowledged (room events exist, collab-only), delegation accepted/rejected (partly `collab_delegation`/handoff states), drift warning (`drift_graph.py`, `fleet_drift` are config/graph drift, not agent drift). No cross-source SSE with `Last-Event-ID`/cursor resume (replay is last 100 only); no replay-state reconstruction API for the UI (`replay.py` is 42 l, session journal only; `projection_history.py`, `history_cursor.py`, `durable_history.py` are candidates). Redaction exists (`redact.py`, `_redact_event`, `deployment_redact.py`); privacy filter for paths/errors must be asserted per spec.
Best integration points:

 (c) Terminal map: `herdr_engineering/agent_ops_tui.py` (stdlib, based on `pane_viewer.py` + `md_render.py` ANSI) launched as `herdr-eng agent-ops map` (register in `cli.py` subparsers, cli.py:166-305 style); consumes same API/SSE as web; optional herdr plugin entry only if needed (`deploy/herdr-agent-ops-plugin/herdr-plugin.toml`, mirror cp-feed plugin).
