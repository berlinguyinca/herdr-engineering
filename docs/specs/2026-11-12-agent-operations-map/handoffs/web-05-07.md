## Limitations
- No pane-open mechanism exists in the web app. Double-click and `O` emit the `agent-ops:open-pane` CustomEvent (detail: node id, agent id, session id); nothing listens yet.
- API-key-only reads see no rooms: the fixture events are org-scoped, so agents appear in a "No room" cluster.
- SSE auth is same-origin with no custom headers (EventSource cannot set them); resume is by cursor in the query string.
- On a phone the map keeps a 560px minimum width and scrolls inside the stage (visible in the 390 screenshots).
- Dense parallel-edge labels can still overlap a node's state text (see "Delegation planned" near "Needs attention" in the 1440 shots) and the model label truncates with an ellipsis on long names.
