# WC-002 — Weekly activity summary
Scope: read-only weekly metrics calculated from available dated events. Add server aggregation only if existing APIs cannot supply accurate event windows. Use user-configured timezone and DST-safe [start,end) boundary.
Acceptance: started/completed independently counted by timestamp, open is present snapshot and labeled accordingly, paused quota requires evidenced reason; absent historical evidence shows 'unknown/partial', never 0. No title heuristic or double count. Tests with event duplicates, DST, stale sources, reassociation.
