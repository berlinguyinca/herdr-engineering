# P07 — Rakazo agent and safeguarded external actions

**Depends on:** previous gated phases; see README dependency graph

## Deliverable and implementation contract
Audit and extend existing Rakazo/Herdr personal-assistant adapter; do not fork a separate assistant service. Map Rakazo identity to HCN participating agent and Pi task broker. Room-aware authorized conversation, memory scopes (personal/private, room/shared, project) with explicit disclosure rules; agent cannot use personal memory in a shared room without authorization. Expose `email.draft`, `email.send`, calendar, GitHub through existing user-scoped integration adapters where supported. External actions governed by capability-scoped approval records including exact content/recipients/attachments, actor/expiry, no replay; idempotency keys on sends and reconciliation after ambiguous provider response. All emails with artifact links obey sharing scope and require user approval by policy (especially novel recipients). Room displays concise status and approval; users may approve in Pi or WebUI only once. Prevent prompt injection from attachments/room messages. Gate: draft from task evidence, approve once, send once, audit delivery result; revoke blocks future actions; safe failure when provider unavailable.

## Required workflow
1. Re-audit relevant code and open PRs; record existing features and exact file paths.
2. Write/update schema and migration plan before implementation; change only owned domains.
3. Implement in unique worktree/feature branch; use existing conventions and tests.
4. Update docs, release notes and rollback/feature flags where relevant.
5. Run focused and repository standard test suites, security and compatibility cases.
6. Add file/command evidence to `evidence/P07-RESULT.md`; label completed, partial or blocked truthfully.
7. Stop if acceptance gate fails. Do not silently skip, mark completed or advance.

## UX contract
Default shows purpose, human-readable progress, next needed action and resulting deliverables. Verbose logs only on expand; no unnecessary user prompts, notifications or manual model selection.
