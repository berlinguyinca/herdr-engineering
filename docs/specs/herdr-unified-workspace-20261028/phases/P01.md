# P01 — Canonical identity, contracts and authorization

**Depends on:** previous gated phases; see README dependency graph

## Deliverable and implementation contract
Define OpenAPI/JSON schema for project, room, team, mission, issue, task, agent, agent_session, host, artifact, artifact_version, review, decision, external_action, and event. Stable IDs, external aliases, tenant/user/visibility scope, version/ETag, timestamps, `trace_id`, correlation/causation IDs, actor, source sequence, and concrete reference URIs. Typed edges: `contains`, `assigned_to`, `depends_on`, `delegated_to`, `spawned`, `reviews`, `implements`, `produced`, `derived_from`, `discussed_in`, `supersedes`, `references`, `approved_by`, `notified_via`. Specify authoritative ownership and correlation lookup. Define capability/action broker: discover, authorize, approve, invoke; grants are intersected (room & artifact & account & execution). Ensure all reads, graph traversal, search, subscriptions and exports re-check ACL. Taint untrusted room content, forbid privilege escalation through summarization. Define subscribe/replay snapshot endpoint and cursor idempotency contract; migrations backward compatible. Gate: schema contract fixtures, permission matrix, adversarial tests and consumer compatibility.

## Required workflow
1. Re-audit relevant code and open PRs; record existing features and exact file paths.
2. Write/update schema and migration plan before implementation; change only owned domains.
3. Implement in unique worktree/feature branch; use existing conventions and tests.
4. Update docs, release notes and rollback/feature flags where relevant.
5. Run focused and repository standard test suites, security and compatibility cases.
6. Add file/command evidence to `evidence/P01-RESULT.md`; label completed, partial or blocked truthfully.
7. Stop if acceptance gate fails. Do not silently skip, mark completed or advance.

## UX contract
Default shows purpose, human-readable progress, next needed action and resulting deliverables. Verbose logs only on expand; no unnecessary user prompts, notifications or manual model selection.
