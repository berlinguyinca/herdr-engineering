# P02 — Persistent Work Graph and reconciliation

**Depends on:** previous gated phases; see README dependency graph

## Deliverable and implementation contract
Extend existing Postgres event/graph projections, not another DB. Entity tables, typed edge tables with uniqueness, immutable event linkage, source-of-truth refs, versioning and tombstones. Support project/issue/task-centric query endpoints, cursor paging, filtered search, history-as-of timestamp, graph snapshots, diagram layout document with per-user overrides. Record team role assignments and sessions as historical facts; do not delete when agents exit. Idempotent ingest, out-of-order events, retries and reconciliation workers checking source API for gaps. Persist room/workspace/agent instance IDs currently missing in Pi/Herdr session ingest. Add indexes by scope/project/issue/task/artifact/version. Prevent tenant information leaks via edges, counts and search. Gate: graph recovers from a clean replay; all graph nodes/edges link to source evidence; no orphan artifacts after reconciliation.

## Required workflow
1. Re-audit relevant code and open PRs; record existing features and exact file paths.
2. Write/update schema and migration plan before implementation; change only owned domains.
3. Implement in unique worktree/feature branch; use existing conventions and tests.
4. Update docs, release notes and rollback/feature flags where relevant.
5. Run focused and repository standard test suites, security and compatibility cases.
6. Add file/command evidence to `evidence/P02-RESULT.md`; label completed, partial or blocked truthfully.
7. Stop if acceptance gate fails. Do not silently skip, mark completed or advance.
