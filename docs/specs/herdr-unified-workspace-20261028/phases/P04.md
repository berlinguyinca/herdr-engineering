# P04 — Native Pi terminal room interface

**Depends on:** previous gated phases; see README dependency graph

## Deliverable and implementation contract
Develop Pi extension/TUI and `pi room` CLI adapter using HCN API; avoid a second chat service. Default: `pi room list|join|attach|history|leave`, Pi `/rooms`, `/room join`, `/room catchup`, agent mention and minimal input composer. Events stream using HCN mechanisms with reconnect cursor, dedup, gap recovery and low-noise status. One screen: chat, active parent task card and attention count. Explicit toggles for activity and expert diagnostics; preserve current Pi private session and no cross-context leakage. Attach session requires independent terminal authorization; detach never kills agent. Markdown, mentions, accessible keybindings, screenreader labels, stable scroll, server-side pagination, slow-network mode. Room and Pi identities mapped with revocable credentials securely stored in OS keychain/0600. Gate: chat synchronized between Pi and WebUI, reconnect from second host, no duplicate events, standalone fallback when HCN offline.
