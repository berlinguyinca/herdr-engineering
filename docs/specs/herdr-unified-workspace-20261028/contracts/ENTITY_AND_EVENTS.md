# Core schema proposal (adapt to existing source; no duplicate ownership)

Canonical ID `urn:herdr:<kind>:<uuid>` or existing stable domain ID with canonical alias table; immutable identity across hosts, renamed rooms, and runtime restarts. `node`: `{id,type,scope,external_ref,display_name,status,created_at,updated_at,source,version}`. `edge`: `{id,from_id,to_id,type,source_event_id,created_at,visibility_scope,revision}`. `event`: `{event_id,schema_version,source,source_sequence,actor_id,scope,occurred_at,received_at,trace_id,correlation_id,causation_id,entity_refs,payload_ref}`. Superseding and tombstoning are explicit events; never alter immutable evidence. Existing HCN IDs and artifact version IDs win over synthetic references. Resolve project and issue aliases from canonical APIs.

Minimum API capabilities to implement by EXTENDING existing routes: list own teams/rooms; room post/read/subscribe with cursor; task submit/status/steer; graph projection by root node and as_of time; artifact registry lookup and version listing; attention queue and approval decision; ability to register external assistant tool results. Use ETags/version compare-and-swap and idempotency tokens on mutations; contract tests between Pi, Herdr, Rakazo.

ACL: scope filtered before graph traversal AND edge expansion; return not-found/forbidden without metadata leak. Authorization is product of user role, agent delegation, room grant, artifact grant, action capability and risk policy. Read-only room grant does not enable task execution or email. Every operation records actor/intent/evidence.
