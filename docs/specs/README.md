# Normative Specs

These files are the current implementation authority. Archived predecessor specs explain lineage but do not override this directory.

Order is defined by `../../SPEC_MANIFEST.yaml`.

Every implementation phase must produce:

1. implementation/configuration changes;
2. automated tests;
3. a reproducible validation command;
4. documentation updates;
5. evidence in `../../STATUS.md`;
6. a coherent commit/PR reference.

A phase is not complete because code exists; its **exit gate** must pass.
