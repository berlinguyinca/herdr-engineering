## Spec 07: quota, eviction, admission, slot suggestion
Plan: (1) config keys `eviction.{destructive_enabled,hard_cap_gib,max_entries_per_run}` and `adaptive_slots.{enabled,min_slots,max_slots}` (defaults off, fail-closed; reuse `local.capacity_gib`, `local.min_free_disk_percent`, `cleanup.{min_idle_hours,max_evict_per_pass_gib}`); (2) new `build_cache_policy.py`: pure `plan_eviction`, `scan_cache`, `remove_planned`, `run_eviction`, `recommend_slots`; (3) CLI `build-cache-evict [--apply]`, slot suggestion in `build-coordinate --status --json` and `build-cache-inventory`; (4) tests first in `tests/test_build_cache_policy.py`.
Completed: sccache manages its own LRU to `capacity_gib`; the manager only plans removal of individual cache files (oldest last-used first, idle floor, bounded by entries and bytes, never `target` paths) when usage exceeds `hard_cap_gib`; between the caps it is report-only. Dry-run is default, creates no files. Apply needs `--apply` AND `eviction.destructive_enabled`; takes `build-maintenance.lock` LOCK_EX|LOCK_NB (`busy` when builds run), blocks on any related active lease or unreadable registry, and rechecks each file before unlink (regular file not symlink, realpath containment, size/mtime unchanged, lease re-read). Low free disk: admission already refuses (`low_free_disk`, spec 03); the evict report shows `admission` and never deletes because of pressure. Slot suggestion: advisory, from builds.jsonl tail + getloadavg + MemAvailable, clamped to `[min_slots,max_slots]`; only `adaptive_slots.enabled: true` makes `build-coordinate` use it (and only when `--slots` is absent).
Not done: no timer/companion invocation of eviction (manual CLI only); no real sccache run; entries are files, not sccache-aware (sccache has no offline LRU API); hard cap is a backstop, not a tuning of sccache's own limit; no shared/S3 quota (spec 06 inventory only).
Risks: file atime may be noatime (falls back to mtime); a running sccache server outside the gate could write during apply (mitigated by mtime recheck, not eliminated); tests use sparse files for the CLI path; `max_slots` is not tied to `execution.max_build_slots`.
